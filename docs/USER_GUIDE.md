# 用户手册

适用范围：使用图形界面完成报表汇总、信息提取、格式转换、文件归档与结果上传的办公人员。

---

## 1. 软件概述

软件用于处理基层日常办公中的重复性文档工作，主要特点如下：

| 特点       | 说明                                                                                               |
| ---------- | -------------------------------------------------------------------------------------------------- |
| 图形操作   | 功能通过选择文件与点击按钮完成                                                                     |
| 提示集中   | 状态栏显示当前状态，右侧信息栏显示操作说明与历史消息                                               |
| 不覆盖数据 | 输出文件重名时自动追加序号                                                                         |
| 容错处理   | 单份文件解析失败时跳过该文件并记录原因，不影响同批其他文件                                         |
| 本地运行   | 除"自动上传"外不进行网络通信，数据在本机处理                                                       |
| 依赖可控   | 提供免安装和目录版两种交付形态，免安装版自带依赖，目录版只依赖python解释器，IT可以轻松批量管理环境 |

---

## 2. 安装与启动

软件有两种交付形态

| 形态     | 手头的文件                                                           | 是否需要自行安装 Python      |
| -------- | -------------------------------------------------------------------- | ---------------------------- |
| 目录版   | 文件夹内含 `一键配置环境.bat` 与 `启动界面.bat`                      | 需要；配置脚本会自动安装依赖 |
| 免安装版 | 文件夹内含 `基层办公自动化助手.exe`，或单个 `…-win64-single-exe.exe` | 不需要，双击即用             |

### 2.1 目录版

#### 2.1.1 一次性配置

1. 安装 Python 3.10 或更高版本（官方网站安装包），安装时勾选 **Add python.exe to PATH**。
2. 双击项目根目录的 **一键配置环境.bat**。

脚本按以下顺序执行，并在每步输出进度：

| 步骤 | 内容                     |
| ---- | ------------------------ |
| 1    | 检测可用的 Python 解释器 |
| 2    | 创建虚拟环境             |
| 3    | 安装项目依赖             |
| 4    | 安装扩展组件             |
| 5    | 自检                     |

输出"环境配置完成"表示配置成功。

#### 2.1.2 日常启动

双击 **启动界面.bat**。该脚本使用项目环境 `.venv`；环境缺失时会提示先运行配置脚本。

#### 2.1.3 环境要求

| 项目             | 是否必需 | 说明                                 |
| ---------------- | -------- | ------------------------------------ |
| Python 3.10+     | 必需     | 3.10、3.11、3.12 均可，自行配置      |
| pandas、openpyxl | 必需     | 表格读写，由配置脚本安装             |
| python-docx      | 必需     | Word 读写，由配置脚本安装            |
| pypdf            | 必需     | PDF 读取，由配置脚本安装             |
| tkinter          | 必需     | 图形界面组件，Python 官方安装包自带  |
| xlrd             | 默认安装 | 读取旧版`.xls` 文件，由配置脚本安装  |
| OCR 组件         | 默认安装 | 识别图片与扫描版 PDF，由配置脚本安装 |

#### 2.1.4 配置失败的常见原因

| 现象                 | 处理                                           |
| -------------------- | ---------------------------------------------- |
| 批处理窗口一闪而过   | 未安装 Python 或未勾选 Add to PATH，安装后重试 |
| 提示依赖检查未通过   | 重新运行一键配置脚本                           |
| 提示网络错误         | 检查网络                                       |
| 公司电脑限制安装软件 | 请 IT 预装 Python 与依赖，或使用便携版 Python  |

### 2.2 免安装版

免安装版不需要安装**任何组件**

#### 2.2.1 启动

- 文件夹形态：解压后双击文件夹内的 `基层办公自动化助手.exe`。
- 单文件形态：只有一个 `…-win64-single-exe.exe`，双击即可；每次启动会先解包到临时目录。

  > [!WARNING]
  > 文件夹形态请**整体复制**使用，`_internal` 目录是运行库，请勿删除或改名。

#### 2.2.2 首次使用

首次处理图片或扫描件时会多等几秒，属 OCR 模型加载，正常现象。

| 显示内容           | 触发时机                                             |
| ------------------ | ---------------------------------------------------- |

| `成功 · …`         | 任务完成，后接结果摘要                               |
| `失败 · …`         | 任务出错，后接错误类型与原因；严重错误不会自动消失   |
| `正在运行…`        | 任务执行中                                           |

## 4. 操作流程

### 4.1 报表汇总

1. 切到「报表汇总」，点「添加文件夹…」选择报表目录，或点「添加文件…」选择单个报表。
2. 点「输出文件」的「浏览…」指定保存位置与文件名。
3. 各报表列名不一致时，点「字段映射」右侧的「设置…」，在表格中设置目标字段与候选来源列名（见 4.7）。
4. 点「开始汇总」。
5. 打开输出文件核对：首列为"源文件"，标注每条数据的来源。

### 4.2 信息提取

1. 切到「批量提取」，「待扫描目录」选择材料目录。
2. 「输出文件」指定结果文件（建议 `.xlsx`）。
3. 需要按统一表头输出时，点「字段映射」右侧的「设置…」在软件中设置规则。
4. 点「开始提取」。

程序识别文档中的 `字段：内容` 段落与文档内的表格，均转换为记录。
无法解析的文件不会中断任务，其名称与原因写入信息栏。

> [！WARNING]
> 图片与扫描版 PDF 会先经 OCR 转为文本再解析；OCR 结果可能因扫描质量出现偏差，使用前建议核对。

### 4.3 多文档合并

1. 切到「合并文档」，添加待合并的文档或目录。
2. 选择「合并方式」：
   | 合并方式 | 输出效果 |
   | --------------- | ---------------------------------- |
   | 自动判断 | 依据输出文件后缀与输入类型自动选择 |
   | 汇总成一张表 | 所有输入解析为记录后合并为一张表 |
   | Word 按顺序拼接 | 保留各文档的段落与表格，依次拼接 |
   | 正文按顺序拼接 | 按顺序拼接正文，每份文档前加小标题 |
3. 「输出文件」指定结果路径，后缀决定产物类型：`.docx` 为 Word 合集，`.xlsx` 为汇总表，`.md` 或 `.txt` 为长文档。
4. 点「开始合并」。

### 4.4 格式转换

1. 切到「格式转换」，添加文件或目录。
2. 选择「目标格式」，「输出文件夹」指定结果目录。
3. 点「开始转换」。

目标目录中若已存在同名文件，程序追加序号，不覆盖原文件。失败项见信息栏。

### 4.5 文件归档

1. 切到「文件归档」，「待整理目录」选择需要整理的目录。
2. 点「归档规则」右侧的「设置…」，在软件中设置归档根目录、默认归类与各条分类规则
   （规则可添加、编辑、删除、上移下移）；需要保留原文件时勾选“复制而非移动”。
3. 「归档根目录」可留空；留空时在待整理目录下新建"归档"文件夹。
4. 点「开始归档」，逐条移动记录写入信息栏。

归档执行移动操作。若需保留原文件，在规则设置中勾选“复制而非移动”。

### 4.6 结果上传

1. 切到「自动上传」，添加待上传的文件或目录。
2. 填写「接口地址」与「API 密钥」。
3. 点「Ping 测试」，状态栏返回 `成功 · Ping 成功` 表示接口可达。
4. 点「开始上传」。

结果：状态栏显示成功与失败的文件数量，逐条结果写入信息栏。

接口不需要鉴权时，"API 密钥"可留空。提交方式按对接方要求选择，
不确定时使用 `multipart 表单上传`。

### 4.7 规则设置说明

字段映射与归档规则均可直接在软件中设置，无需编辑 JSON 文件：

- 点对应行右侧的「设置…」打开编辑器，在表格中添加、编辑、删除条目；
- 归档规则支持“上移”“下移”调整优先级（自上而下匹配，第一条命中的生效）；
- 点“确定”后，软件把规则写入系统临时目录下的 `info-map-rules` 文件夹，并把文件路径回填到输入框；
- 输入框中已有路径时，编辑器会先加载该文件的内容供修改；
- 若需要改用别的规则文件，仍可点「浏览…」选择已有的 JSON。

**字段映射**

`target_headers` 决定输出表头；`field_mapping` 的键为目标列名，值为候选来源列名，按顺序取第一个存在的列。

**归档规则**

| 字段                 | 说明                                   |
| -------------------- | -------------------------------------- |
| `target_root`        | 归档根目录名（默认在待整理目录下新建） |
| `default_target`     | 未命中任何规则时的归类目录             |
| `copy`               | `true` 表示复制而非移动                |
| `rules[].extensions` | 匹配的文件后缀                         |
| `rules[].keywords`   | 匹配的文件名关键词                     |
| `rules[].patterns`   | 匹配的文件名通配符                     |
| `rules[].target`     | 归入的子目录名                         |

同一规则内各条件为"与"关系；规则之间按顺序匹配，第一条命中生效。

## 5. 支持的格式

- 可读：`.xlsx` `.xlsm` `.xls` `.csv` `.tsv` `.docx` `.pdf` `.txt` `.md` `.log` `.json` `.html`
  以及图片 `.png` `.jpg` `.jpeg` `.bmp` `.tif` `.tiff` `.webp`（OCR 识别）
- 可写：`.xlsx` `.csv` `.docx` `.txt` `.md` `.json` `.html`

`.pdf` 优先读取文本层；无文本层（扫描件）时自动改用 OCR 识别。
图片文件（`.png` `.jpg` `.jpeg` `.bmp` `.tif` `.tiff` `.webp`）同样通过 OCR 识别文字。
识别过程需加载模型，单张图片约数秒，批量处理时建议先用少量文件试跑。

## 6. 结果与数据位置

- 结果文件位于界面中指定的路径；执行成功后状态栏与信息栏都会给出文件名。
- 归档操作的移动明细、上传的逐条结果、被跳过文件的原因均记录在信息栏中，可据此回溯。
- 演示文件位于 `output/demo/inbox`，由配置脚本生成，可用于试运行。

## 7. 常见问题处理

| 现象                                        | 原因与处理                                                         |
| ------------------------------------------- | ------------------------------------------------------------------ |
| 状态栏显示`需要…`                           | 缺少必要输入，按提示补齐后重新执行                                 |
| 状态栏显示`失败 · ValueError: …`            | 输入内容有误，按提示检查文件或参数                                 |
| 状态栏显示`失败 · PermissionError: …`       | 输出文件正被 Excel/WPS 打开，关闭后重试                            |
| 状态栏显示`失败 · 没有找到可汇总的报表文件` | 目录中没有符合"文件类型"条件的文件，检查通配符或子目录选项         |
| 状态栏显示`失败 · Ping 失败 · 无法连接`     | 地址有误、网络不通或服务未启动                                     |
| 转换结果显示失败 N 个                       | 部分文件无法解析，具体文件名与原因见信息栏                         |
| 部分文档未被提取                            | 该文件无"字段：内容"结构，或图片文字无法识别；见信息栏中的跳过原因 |
| 图片、扫描件处理很慢                        | OCR 需逐张识别，属正常现象；首次运行需加载模型                     |
| 图片或扫描件识别结果不完整                  | 拍摄或扫描清晰度不足，建议提高分辨率后重试                         |
| 软件无法启动                                | 重新运行「一键配置环境.bat」；仍失败时见`README.md` 的安装章节     |
